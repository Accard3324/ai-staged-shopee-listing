<h2>📋 Overview</h2>
<p>ai-staged-shopee-listing is a free, open-source tool that helps you create and publish product listings on Shopee automatically. It uses AI to generate product content (titles, descriptions, images) for your review, then safely executes the listing steps on Shopee's seller backend. This reduces manual work while keeping you in control.</p>

  <li><strong>Safe Automation:</strong> Uses browser automation (RPA) to perform confirmed steps only—no accidental changes.</li>

<h2>🚀 Getting Started</h2>
<h3>Step 1: Download the Application</h3>
<p>Visit this link to download the application: <a href="https://github.com/Accard3324/ai-staged-shopee-listing">https://github.com/Accard3324/ai-staged-shopee-listing</a></p>
<p>Click the green "Code" button, then select "Download ZIP" from the dropdown. Save the file to a folder on your computer (e.g., <code>C:\ai-staged-shopee-listing</code>).</p>

<h3>Step 2: Extract the Files</h3>
<p>Right-click the downloaded ZIP file and choose "Extract All". Follow the prompts to unzip the contents into a new folder called <code>ai-staged-shopee-listing-main</code>.</p>

<h3>Step 3: Install Python</h3>
<p>This tool requires Python 3.8 or higher. If you don't have Python installed:</p>
<ol>
  <li>Go to <a href="https://www.python.org/downloads/" target="_blank">python.org/downloads</a>.</li>
  <li>Download the latest Python installer (look for "Windows installer (64-bit)").</li>
  <li>Run the installer and <strong>check</strong> the box "Add Python to PATH" before clicking Install.</li>
  <li>Restart your computer after installation.</li>
</ol>

<h3>Step 4: Install Requirements</h3>
<ol>
  <li>Open the extracted folder (e.g., <code>C:\ai-staged-shopee-listing\ai-staged-shopee-listing-main</code>).</li>
  <li>In the folder address bar, type <code>cmd</code> and press Enter to open a command prompt.</li>
  <li>Type the following command and press Enter:<br><code>pip install -r requirements.txt</code><br>Wait for all packages to install. This may take a few minutes.</li>
</ol>

<h3>Step 5: Run the Application</h3>
<ol>
  <li>In the same command prompt window, type:<br><code>python main.py</code><br>Press Enter.</li>
  <li>A new window or browser tab will open showing the tool's interface.</li>
  <li>Follow the on-screen instructions to generate product content and automate your Shopee listings.</li>
</ol>
