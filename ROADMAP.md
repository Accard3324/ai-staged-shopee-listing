# Roadmap

Roadmap items are plans, not current capabilities.

## Near term

- Replace remaining example store/sheet mappings with a fully generic configuration layer.
- Add sanitized demo fixtures so new contributors can run a complete offline workflow.
- Add a browser-page compatibility matrix and replayable DOM fixtures.
- Improve provider-independent evaluation for objective image facts, titles, and descriptions.
- Publish a short, privacy-reviewed demo and setup guide.

## Planned AI capabilities

- Optional AI product-image generation with explicit provenance metadata, operator approval, and marketplace-policy checks.
- Image editing variants that preserve the source asset and record the model/provider used.
- Provider-neutral structured-output adapters and cost/latency evaluation.

## Platform expansion

- Additional Shopee regions after selector, category, and policy validation.
- Official marketplace API adapters where authorized and available.
- A plugin interface for other marketplaces without coupling their rules to the Shopee executor.

## Safety and maintenance

- Signed release artifacts and reproducible source packages.
- Stronger secret scanning and synthetic security fixtures.
- Optional Codex Security analysis for the public repository if program access is granted.
